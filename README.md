# BufferGrid Technologies Website

A responsive React + TypeScript + Vite website for BufferGrid Technologies.

## Requirements
- Node.js 18.18+ (Node 20+ recommended)
- npm

## Run locally
1. Extract the ZIP.
2. Open the `buffergrid-technologies` folder in VS Code.
3. Open the terminal in that folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Before publishing — important checklist
- [ ] Add real project screenshots to `public/images/projects/` using the exact filenames in that folder's README.
- [ ] Replace `hello@buffergrid.tech` in `src/App.tsx` with your active business email. Do not use this address unless you own/configure it.
- [ ] The contact form currently opens the visitor's default email application. It does NOT submit to a server. Connect Formspree, Web3Forms, Resend, or your own backend before relying on it for enquiries.
- [ ] Confirm the business email, domain, social links and legal business details before launch.
- [ ] Review all copy, service claims and portfolio descriptions for accuracy.
- [ ] Test on mobile and desktop.
- [ ] Configure hosting and domain.
